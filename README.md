# Trove Backend

## Project Overview

Trove is a GST Billing, Accounting, and Multi-Bank Transaction Management System built using the MERN Stack. This backend provides secure REST APIs for authentication, customer management, product management, billing, invoicing, payments, reports, and banking modules.

---

## Tech Stack

- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT Authentication
- REST API
